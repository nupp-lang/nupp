Local spike: third-party components

This experiment downloads upstream binaries for local testing. It is not a redistribution-ready Nupp runtime package.

  • QEMU-Wasm: GPLv2; firmware has separate licenses.
  • Pinned upstream images: QEMU, Linux 6.12.43, firmware, and Alpine initramfs. The spike extracts BusyBox and musl from the initramfs.
  • LuaJIT: MIT notice. Built without changes from Nupp's pinned source revision.
  • musl: MIT. Alpine's libgcc runtime has GCC runtime licensing and exceptions.
  • xterm-pty: MIT notice.

Before distributing an export, rebuild or obtain complete corresponding source for the exact QEMU, Linux, BusyBox and firmware binaries, preserve all required notices, and package the required source and build scripts. The upstream image commit pins binary bytes; it does not establish complete source provenance. Linking these project homepages alone is not a completed GPL source-distribution package.

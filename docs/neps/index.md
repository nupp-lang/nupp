# Nupp Enhancement Proposals

A Nupp Enhancement Proposal records why a part of Nupp is shaped the way it is:
the problem, the design that answered it, what that design looks like in source
and what it lowers to, and the designs that lost. It does not describe how Nupp
behaves today, and the rest of this site wins wherever the two disagree.

See [NEP 1](0001-nep-process.md) for how to write one. A proposal is published
by existing: the table below is generated from the files in this directory, one
row per proposal carrying its number, its title, and the status its own
frontmatter declares.

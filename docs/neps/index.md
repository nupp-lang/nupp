# NEP 0: Index

A Nupp Enhancement Proposal records why a part of Nupp is shaped the way it is:
the problem, the design that answered it, what that design looks like in source
and what it lowers to, and the designs that lost. It is not a description of how
Nupp behaves today — the rest of this site is that, and wins wherever the two
disagree.

[NEP 1](0001-nep-process.md) says how to write one. Every proposal is listed
below by existing, with whatever status its own frontmatter carries.

# NEP 0: Index

A Nupp Enhancement Proposal records **why** a part of Nupp is shaped the way it
is: the problem, the design that answered it, the designs that lost, and what
the decision assumed. It is not a description of how Nupp behaves today — the
rest of this site is that, and wins wherever the two disagree.

[NEP 1](0001-nep-process.md) says how to write one.

The table below is generated from the proposals themselves, so a proposal is
listed by existing and its status is whatever its own frontmatter says.

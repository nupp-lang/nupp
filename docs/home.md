## Designed for systems work

Nupp keeps Lua's directness while adding the contracts needed for native
programs: nominal types, ownership, deterministic cleanup, checked C interop,
and a self-hosted toolchain.

## Documentation

- Follow [getting started](guide/getting-started/index.html) to check, build,
  and run a small project.
- Use [modules and types](guide/modules-and-types/index.html) to design a clear
  public API.
- Read [calling C safely](guide/c-interop/index.html) before importing a native
  library.
- Use [managing resources](guide/managing-resources/index.html) for files,
  sockets, handles, and deterministic cleanup.
- Learn [annotations and lints](guide/annotations-and-lints/index.html) to make
  project policy explicit.
- Browse the generated API below for the compiler's public modules.
